# palette — astronaut-light

Светлая кремово-оранжевая тема. Источник всех цветов — [`astronaut-light.json`](astronaut-light.json);
отсюда их берут Ghostty, tmux, Neovim, glow, fish (tide, fzf), yazi, lazygit,
btop, delta, Zed, sketchybar, borders, Arc, Obsidian, Happ и Telegram.

Правило: кремовый — основа, оранжевый — главный акцент, остальные семьи дают
разнообразие. Эталон раскладки цветов по ролям — Obsidian
([`obsidian-colors.md`](obsidian-colors.md)): заголовки navy → pine → gold →
ember → tan → stone, ссылки и папки emerald, выбранное — peach, рамки — glow.

**Светлые цвета — не для текста.** paper, cream, linen, sand, dune, peach,
butter, mint, mist, glow и flame на кремовом фоне сливаются, если написать ими
текст. От них не отказываемся, но применяем только как **фон, заливку, линию или
рамку**: фон выделения, плашка, тег, полоса цитаты, рамка окна. Текстом на креме —
только цвета с контрастом ≥ 4.5 к `#f1ead8` (ash 3.1 и gold 4.2 — только крупно/жирно
или для второстепенного). Отсюда и ANSI white: 7 = slate, 15 = ash — программы
пишут ими текст.

Тёмный `night` (`#1c1513`) — только для карточек (блоки кода, всплывающие окна,
плашка папки в tmux, панель sketchybar под вырезом), не для основного фона:
основа системы светлая, чтобы экран не бликовал. На night текст — светлый набор
с блоков кода Obsidian (`#e3dccb`, `#e5c15a`, `#7daea3`, `#ef8f4c`…).
