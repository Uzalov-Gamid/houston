## 10. Стандартные цвета Obsidian, которые тема не перекрасила

Почти всё, что Astronaut не задаёт явно, Obsidian берёт из палитры по цепочке переменных
(canvas, mermaid, bases, меню, модалки — всё в cream/linen/sand/ember). Своими остались:

| Где | HEX | Комментарий |
|---|---|---|
| всплывающие подсказки, уведомления | `#191817` фон / `#fafafa` текст | чёрный 90% — выбивается из тёплой гаммы |
| ползунки переключателей, слайдеры | `#ffffff` | чисто белый, не paper |
| точки на холсте (canvas) | `#e4e4e4` | холодный серый |
| цвет карточки canvas по умолчанию | `#c0c0c0` | холодный серый |
| перетаскивание (drag ghost) | чёрный 85% / `#ffffff` | |
| просмотр картинок (lightbox) | `#000000` / `#ffffff` | |
| серая шкала `--color-base-*` | `#ffffff` `#fcfcfc` `#fafafa` `#f6f6f6` `#efefef` `#e4e4e4` `#dadada` `#bdbdbd` `#ababab` `#707070` `#5c5c5c` `#222222` | нейтральные серые, видны в редких местах |

Цвета для canvas и mermaid по номерам: 1 rust `#b0381a`, 2 ember `#b4541b`, 3 mustard `#765500`,
4 olive `#5d6a1c`, 5 emerald `#1f6b5c`, 6 navy `#1e3a5f`, 7 sky `#2f64a0` (mermaid), 8 tan `#87562f` (mermaid).

## 11. Как устроены иконки

Иконки Obsidian — набор **Lucide**: контурные, линия 2px, скруглённые концы и углы, сетка 24×24.
Цвет у иконки не свой: она берёт цвет того, к чему относится (callout, тип файла, состояние).

**Иконки callouts** (цвет иконки = цвет блока, полный, без прозрачности):

| Callout | Иконка Lucide | Цвет |
|---|---|---|
| note | `pencil` | `#24578f` |
| summary / abstract | `clipboard-list` | `#56616b` |
| info | `info` (буква i в круге) | `#2f64a0` |
| todo | `check-circle-2` | `#1f6b5c` |
| tip | `flame` | `#1f6b5c` |
| success | `check` | `#5d6a1c` |
| question | `help-circle` | `#8c6a12` |
| warning | `alert-triangle` | `#b4541b` |
| fail | `x` | `#b0381a` |
| danger / error | `zap` | `#b0381a` |
| bug | `bug` | `#b0381a` |
| example | `list` | `#1e3a5f` |
| quote | `quote` | `#87562f` |

**Знаки в тексте:** `◆` перед H3 — brass `#c49a3a`, 0.7 от размера текста.

**Состояния иконок интерфейса:** покой — stone `#6e6155`, наведение и активная вкладка — ember `#b4541b`.

Принцип, который стоит перенести в систему: одна форма иконок (контур, одна толщина линии) +
цвет по смыслу из палитры + серый в покое и оранжевый при наведении или активности.
