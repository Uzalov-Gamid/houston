# Neovim — шпаргалка

Запуск: `n файл` (alias в fish) или `nvim`. Открыть этот конфиг: `nvimconf`.
Изменения подхватываются при следующем запуске (или `:source %` в `init.lua`).

Конфиг: эта папка — [`init.lua`](init.lua), [`after/ftplugin/`](after/ftplugin/),
[`lsp/`](lsp/) (язык-серверы), [`lua/`](lua/) (дерево, режим чтения, плагины),
[`colors/palette.lua`](colors/palette.lua).

**Без автодополнения кода** — код пишешь сам, так он лучше запоминается.
Язык-серверы только **проверяют** (точка слева, волнистое подчёркивание, текст
ошибки на строке с курсором) и **отвечают на вопросы** (`K`, `gd`). Плагинов
немного и только там, где без них неудобно: git, SQL, закрывающиеся скобки —
ставятся встроенным `vim.pack`, без менеджера плагинов.

`Space` — leader. ★ — настроено в конфиге, остальное — встроенное в Neovim.

★ **Не помнишь клавишу — нажми `Space` и подожди**: снизу справа откроется окно
(which-key) со всеми командами и подписями по-русски; дальше — буква нужной
команды, `h` — раскрыть группу «git: изменения», `Backspace` — назад, `Esc` —
закрыть. Так же работают `g` (переходы), `]` / `[` (следующее / предыдущее),
`z` (сворачивание), `Ctrl-w` (окна). `Space ?` — клавиши, которые есть только в
текущем окне: дереве, режиме чтения, файле с язык-сервером.

## Языки

| Файлы | Отступ | `Space r` запускает ★ | Что ещё |
|---|---|---|---|
| Python `.py` | 4 пробела | `python3 файл` (или `.venv/bin/python`, если есть) | — |
| C `.c` `.h` | 4 пробела | `make`, если рядом есть `Makefile`; иначе `cc -Wall -Wextra -Werror -std=c11` и запуск | `.h` — это C, а не C++; при сохранении — `clang-format` (`.clang-format` рядом или выше, иначе Google + 4 пробела) |
| Markdown `.md` | 2 пробела | открыть файл в Obsidian | ★ **`Space p` — режим чтения как в Obsidian** (см. ниже); в редакторе — цвета заголовков, `[[ссылки]]`, `==выделение==`, `#теги` и блоки `> [!tip]` с иконками; перенос строк по словам |
| YAML (compose, k8s, Ansible, Actions, Prometheus) | 2 пробела | — | подсветка **колонки** курсора, чтобы ключи стояли ровно; `#` и `:` не сбивают отступ |
| Dockerfile | 4 пробела | `docker build` из папки файла | |
| Shell `.sh` | 2 пробела | `bash файл` | |
| Makefile | **табы** (видны как `»`) | `make` | make требует табы в рецептах |
| Terraform `.tf` `.tfvars` | 2 пробела | — | `.tf` правильно распознаётся как Terraform |
| Jinja / Ansible `.j2` | 2 пробела | — | подсветка `{{ }}` и `{% %}` |
| JSON, TOML, SQL, HTML, CSS, JS/TS, Lua | 2 пробела | — | |
| Сообщение коммита | — | — | перенос текста на 72 символах |

★ **Линии уровней вложенности** `│` на каждом уровне отступа — особенно спасают в
YAML и Python. Их шаг подстраивается под язык (2 или 4).

★ Если в проекте есть `.editorconfig`, его правила главнее этих (поддержка встроена).
В самом `~/.config` он тоже есть: Lua в `sketchybar/` — табы, в `nvim/` — 2 пробела.

## Язык-серверы (LSP) ★

Каждый сервер — один файл в [`lsp/`](lsp/) (команда, типы файлов, корень проекта),
список включённых и клавиши — [`lua/lsp_setup.lua`](lua/lsp_setup.lua). Если
программа сервера не установлена, он молча пропускается. `:Lsp` — какие серверы
работают в текущем файле.

| Файлы | Сервер | Что проверяет |
|---|---|---|
| Python | `pyright` | типы, импорты, опечатки в именах |
| C `.c` `.h` | `clangd` (Xcode) | ошибки компиляции, предупреждения; с `compile_commands.json` — точнее |
| Bash / sh | `bash-language-server` + `shellcheck` | кавычки, `$1` без кавычек, опасные конструкции |
| YAML | `yaml-language-server` | по схемам schemastore.org: **GitHub Actions**, **docker-compose**, **Ansible**, Helm values…; **Kubernetes** — для файлов в `k8s/`, `manifests/` и `*.k8s.yaml` |
| `compose.yaml`, `docker-compose.yml` | `docker-compose-langserver` + yamlls | сервисы, образы, порты |
| Dockerfile | `docker-langserver` | инструкции, порядок, опечатки |
| nginx (`*.nginx`, `…/nginx/*.conf`) | `nginx-language-server` | директивы и контекст |
| JSON, HTML, CSS | `vscode-*-language-server` | синтаксис |
| TOML | `taplo` | синтаксис |
| Lua | `lua-language-server` | этот конфиг и sketchybar (`vim`, `sbar` известны) |
| SQL | `postgrestools` | синтаксис Postgres; с `postgrestools.jsonc` (подключение к базе) — таблицы и столбцы |
| Terraform `.tf` | `terraform-ls` | ресурсы, переменные |
| Helm (`templates/` рядом с `Chart.yaml`) | `helm_ls` | шаблоны чарта |
| Ansible (`roles/*/tasks`, `playbooks/`, `playbook*.yml`) | `ansible-language-server` | модули и параметры; `ansible-lint` включается в [`lsp/ansiblels.lua`](lsp/ansiblels.lua) после `uv tool install ansible-lint` |

| Клавиши | Действие |
|---|---|
| `K` | Что это: описание функции / ключа / директивы |
| `gd` / `gD` | Перейти к определению / объявлению |
| `grr` | Где используется |
| `grn` | Переименовать везде |
| `gra` | Действие по месту: исправить, добавить импорт |
| `gO` | Символы файла (функции, ключи) |
| `]d` / `[d` | Следующая / предыдущая проблема (с окошком ошибки) |
| `Space d` | Проблема под курсором полностью |
| `Space F` | Отформатировать файл (C форматируется сам при сохранении) |

Цвета проблем: ошибка — rust, предупреждение — mustard, сведение — sky,
подсказка — emerald. Текст ошибки виден только на строке с курсором, остальной
экран остаётся тихим.

## Скобки и кавычки ★

Плагин `mini.pairs`: `(` `[` `{` `"` `'` `` ` `` сразу ставят пару, курсор — между
ними. Набрал закрывающую — курсор просто перескакивает через уже стоящую.
`Backspace` между пустой парой удаляет обе. **`Enter` между `{}`** раскрывает тело:

```
int main(void) {|}      →  Enter  →      int main(void) {
                                             |
                                         }
```

## Git ★

| Клавиши | Действие |
|---|---|
| `Space G` | **Пульт git** (neogit) в рамке: статус, `s` — добавить, `u` — убрать, `c c` — коммит, `P p` — push, `F p` — pull, `l l` — история, `?` — все клавиши |
| `]h` / `[h` | Следующее / предыдущее изменение в файле |
| `Space h p` | Показать изменение под курсором |
| `Space h s` / `Space h r` | Добавить в коммит / откатить это изменение |
| `Space h b` | Кто и когда написал строку |
| `Space h d` | Все изменения рабочей папки бок о бок (diffview; закрыть — `:DiffviewClose`) |
| `Space h h` | История текущего файла |

Слева у строк — метки: `│` olive — добавлено, `│` mustard — изменено, `▁` rust — удалено.

## Базы данных и SQL ★

Postgres 18 запущен как сервис (`brew services`, стартует сам), база по
умолчанию — с именем пользователя, поэтому `psql` и `pgcli` подключаются без
параметров.

| Клавиши / команда | Действие |
|---|---|
| `Space s` | Панель баз (dadbod-ui): базы → схемы → таблицы; `Enter` на таблице — готовые запросы (первые строки, столбцы, индексы) |
| в окне запроса `Space S` | Выполнить запрос (или выделенный кусок) — результат таблицей снизу |
| `:DB select now()` | Выполнить SQL одной строкой в базе из `vim.g.dbs` |
| `Space H` | **harlequin** в рамке — полноценный SQL-клиент: дерево таблиц, редактор, результаты сеткой, `Ctrl-q` — выход |
| `pgcli` (в терминале) | Консоль Postgres с подсказками и цветом |

Свои базы добавляются в [`lua/plugins.lua`](lua/plugins.lua), таблица `vim.g.dbs`:
`имя = "postgresql://user:password@host:5432/db"`.

## Контейнеры ★

`Space c` — **lazydocker** в рамке поверх редактора: контейнеры, образы, тома,
логи и статистика; `Enter` — подробности, `d` — удалить, `r` — перезапустить,
`q` — выйти. Нужен запущенный Docker (`colima start`).

## Режим чтения Markdown ★

`Space p` рисует заметку так, как её показывает Obsidian с темой Astronaut
([`lua/mdview.lua`](lua/mdview.lua), без glow и плагинов):

- сверху имя файла, под ним **свойства** (front matter) в рамке, теги — пилюлями;
- заголовки лесенкой: H1 navy · H2 pine с золотой линией · H3 `◆` gold · H4 ЗАГЛАВНЫМИ · H5 tan · H6 stone;
- `[!tip]`, `[!question]-` и другие блоки — тонированный фон, цветная полоса, иконка; свёрнутые (`-`) закрыты, как в Obsidian;
- код — тёмная карточка с подсветкой (для языков, разбор которых есть в Neovim) и названием языка;
- таблицы с тонкими линиями, задачи `○` / `✓`, `![[заметка#раздел]]` — сам раздел под зелёной полосой, картинки — по центру колонки.

| Клавиши | Действие |
|---|---|
| `Enter` / `za` на заголовке блока | Свернуть / развернуть блок |
| `Enter` на `[[ссылке]]` | Открыть ту заметку (сразу в режиме чтения); назад — `Ctrl-o` |
| `]]` / `[[` | Следующий / предыдущий заголовок |
| `q` / `Space p` | Обратно в редактор, на то же место |

## Стартовый экран — мини-профиль ★

`nvim` без файла открывает не стандартное приветствие, а профиль
([`lua/dashboard.lua`](lua/dashboard.lua)):

```
  ████████████████████   Astro Naut  @astronaut
  ████████████████████   devops · linux · homelab
  ████    ████    ████   stardate 2026.299 · пн 26 окт · 16:20
  ████    ████    ████   // продуктивного дня, экипаж из одного.

  ❯ gh contributions --last 26w          703/год ·  1 · сегодня 17
    (сетка активности GitHub за полгода, оттенки оранжевого)
  ❯ atuin stats --days 52                  1722 команд · сегодня 247
    ▁▁▃▂▁▅▂▅▁▂▁█▁▅▂▂▁█   python3 32% · git 8% · nvim 7% · gcc 7%
  ❯ nvim --time --week                                        3ч 20м
    пн ▃   вт ▇   ср ▅ …   c 48% · yaml 22% · python 18%
  ❯ sky --city msk
     полнолуние 100% · сегодня       07:21    17:04

  e дерево   f найти   g поиск   n новый   r обновить   q выход
```

- Логотип — identicon, массив `LOGO` в начале файла. Имя, ник, описание и город — **не в репозитории**: в репо стоят нейтральные значения, а твои данные лежат в `lua/local_profile.lua` (в `.gitignore`, шаблон — `local_profile.example.lua`).
- GitHub — через `gh` (кэш на час в `~/.cache/nvim/dashboard`), atuin — его база
  напрямую через `sqlite3`, Луна и солнце считаются локально. Без сети экран
  работает на последнем кэше.
- Время в Neovim считает [`lua/activity.lua`](lua/activity.lua): только активное
  редактирование (пауза > 2 мин не считается), по дням и языкам, в
  `~/.local/share/nvim/activity.json`.
- Снова открыть экран: `:Dashboard`.

## Дерево проекта ★

`Space e` — открыть/закрыть дерево слева ([`lua/tree.lua`](lua/tree.lua), написано
без плагинов). Папки первыми, без `./` и `../`, Nerd-иконки по типам файлов,
текущий файл подсвечен оранжевым, дерево само раскрыто до него.

| Клавиши в дереве | Действие |
|---|---|
| `Enter` / `l` / двойной клик | Открыть файл в основном окне · раскрыть / свернуть папку |
| `h` | Свернуть папку (или перейти к родительской) |
| `a` | Создать файл; имя с `/` в конце — папку (можно `src/utils.c` — создаст и папку) |
| `r` | Переименовать |
| `d` | Удалить — **в Корзину** (спросит подтверждение) |
| `H` | Показать / скрыть файлы с точкой (`.github`, `.env`…) |
| `R` | Обновить |
| `q` | Закрыть дерево |
| `?` | Подсказка по клавишам |

Не показываются никогда: `.git`, `.DS_Store`, `__pycache__`, `node_modules`
(список `NEVER_SHOW` в начале файла). Ширина — `WIDTH`.

## Мелочи

- ★ Файл открывается там, где был закрыт.
- ★ При сохранении удаляются пробелы в конце строк (кроме Markdown, где два пробела — перенос).
- ★ Скопированное мигает подсветкой; `y`/`p` работают с буфером обмена macOS.
- ★ Строка состояния в стиле tmux — скруглённые плашки: режим (NORMAL голубой, INSERT оранжевый, VISUAL жёлтый), файл с иконкой и `●` если не сохранён, справа тип файла и строка:колонка. Терминал, режим чтения и дерево подписаны словами, а не путём `term://…`.
- ★ **Нет нижней строки команд**: `:` и `/` открывают окно ввода по центру экрана
  (в рамке с подписью «команда» / «поиск»), сообщения всплывают окошком **справа
  вверху**, под плашками tmux, и исчезают через 4 с. Это встроенный в Neovim 0.12
  интерфейс *ui2* (пока экспериментальный); `:messages` — история сообщений.
- ★ Над кодом — путь к файлу: `проект › src › telemetry.c ●`.
- ★ Сохранение пишет одну строку: `● telemetry.c · 18 строк · 0.4 КБ`.
- ★ Все всплывающие окна — тонкая голубая рамка без заливки; меню дополнения `Ctrl-n` — тёмная карточка.
- Плагины: `:lua vim.pack.update()` — обновить (версии закреплены в `nvim-pack-lock.json`).
- ★ Swap-файлы выключены (нет предупреждений «swapfile exists»); история отмен всё равно сохраняется.
- `:help <что угодно>` — встроенная документация (`:help gc`, `:help :find`).
