## 2026-11-11 — Obsidian как эталон, nvim для DevOps

### Палитра и цвета по всей системе

- **Эталон — Obsidian.** Все цвета темы Astronaut и сниппета jery-style разобраны в
  [`palette/obsidian-colors.md`](palette/obsidian-colors.md): палитра, роли,
  заголовки, блоки, иконки файлов, граф, полупрозрачные цвета, переведённые в
  сплошные HEX. Правила — [`palette/README.md`](palette/README.md).
- **Правило светлых цветов:** paper, linen, sand, dune, peach, butter, mint, mist,
  glow, flame — только фон, заливка, линия или рамка, **не текст на креме**.
  Тёмный `night` — только карточки (код, всплывающие окна), фон остаётся светлым.
- **Ghostty:** новые ANSI-цвета — синий стал синим (sky), cyan — emerald, яркие —
  pine, gold, navy, espresso; белые 7/15 — slate и ash (раньше сливались с фоном).
  Выделение — персиковое.
- **tmux:** сессия emerald, активное окно — персиковая плашка, папка — тёмная
  плашка, ветка — как тег Obsidian; голубая рамка активной панели; пустая строка
  отступа под панелью.
- **fish:** свой промпт в рамке ([`fish/conf.d/prompt.fish`](fish/conf.d/prompt.fish)),
  после Enter сворачивается в `● команда`, упавшие и долгие команды оставляют
  `✗ exit 1 · 4.2s`. Tide остаётся установленным для возврата. fzf: выбранная
  строка peach, рамка glow.
- **yazi:** файлы раскрашены как в дереве Obsidian (папки emerald, картинки tan,
  PDF rust, архивы ember), выбранное — peach. **lazygit:** выбранная строка peach.
- **Zed:** светлая тема и ANSI встроенного терминала — на точных цветах палитры.
- **sketchybar:** вместо gruvbox — тёмные цвета блоков кода Obsidian (панель под
  вырезом остаётся чёрной); названия пространств — Heavy.
- **Шрифт:** SF Mono везде — подписи sketchybar и терминал Zed (значки — из
  Symbols Nerd Font).
- **Тест палитры:** `python3 palette/test/preview.py`, макет интерфейса —
  `python3 palette/test/nvim-preview.py`.

### Neovim

- **Цвета:** 13 новых ролей из Obsidian; ключевые слова emerald, типы navy,
  операторы sky, поля pine. Одна толщина шрифта в дереве (без жирного).
- **Markdown в редакторе:** заголовки лесенкой, `[[ссылки]]`, `==выделение==`,
  `#теги`, блоки `> [!tip]` с иконкой и цветом.
- **Режим чтения `Space p`** — свой рендер вместо glow, как заметка в Obsidian:
  свойства в рамке, блоки со сворачиванием, код на тёмной карточке с подсветкой,
  таблицы, встраивания разделов, картинки по центру, переход по `[[ссылкам]]`,
  `]]`/`[[` по заголовкам.
- **Интерфейс:** путь над кодом (`проект › src › файл ●`), сообщения справа
  вверху, строка о сохранении `● файл · 18 строк · 0.4 КБ`, рамки окон без
  заливки, подписи «команда» / «поиск» у окна ввода.
- **Язык-серверы без автодополнения** (16): Python, C, Bash (+shellcheck), YAML
  со схемами (k8s, Actions, compose, Ansible), compose, Dockerfile, nginx, JSON,
  HTML, CSS, TOML, Lua, SQL (Postgres), Terraform, Helm, Ansible. `K`, `gd`,
  `grr`, `grn`, `gra`, `]d`, `Space d`, `Space F`.
- **Плагины** (встроенный `vim.pack`, ставятся при первом запуске с
  подтверждением): mini.pairs (скобки), gitsigns, neogit (`Space G`), diffview,
  vim-dadbod + dadbod-ui (`Space s`).
- **В рамке поверх редактора:** lazydocker (`Space c`), harlequin (`Space H`).

### Программы
